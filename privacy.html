Privacy policy

Hermes rclone · last updated 12 November 2026

Hermes rclone is a private desktop utility used by one person to transfer files between their own computer and their own Google Drive. This policy describes what it does with data.

1. Data collected

None. The utility has no analytics, no telemetry, no cookies, no advertising and no crash reporting. It does not create a user profile and does not transmit information to the author.

2. Google user data

  • What is accessed: files and folders in the Google Drive of the account that authorises the utility, using the drive scope.
  • Why: solely to download files the account owner has placed there, and to upload results back to the same Drive.
  • Where it goes: nowhere else. Files move directly between the owner's computer and the owner's Drive over Google's API. The author operates no server that receives, stores or inspects them.
  • What is stored locally: an OAuth access token and refresh token, on the owner's own machine, readable only by that user account. No file contents are cached beyond the working copy the owner asked for.

3. Sharing

No data is sold, rented, shared, or disclosed to any third party. There is no third party involved at all beyond Google's own API.

4. Retention and deletion

Files remain in the owner's Google Drive under the owner's control; deleting them from Drive (or emptying the Drive trash) deletes them. Local working copies can be removed at any time by deleting them from disk. Authorisation can be revoked at myaccount.google.com/permissions, which invalidates the stored tokens immediately.

5. Limited use

The utility's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide the file-transfer function described above.

6. Changes

Any change to this policy will be published on this page with a new "last updated" date.
